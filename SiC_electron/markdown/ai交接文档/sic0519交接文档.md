## 2. 统一计算口径

本窗口最终采用的 i-t 后处理口径如下：

1. 每条 i-t 曲线使用前 5 个点计算 baseline，并从电流中扣除。
2. 对时间点重复值做合并，重复时间点的电流取均值。
3. FWHM 使用基线扣除后的主极性脉冲计算：
   - 正负脉冲分别取绝对主峰；
   - 使用主峰半高 `0.5 * Ipeak`；
   - 左右半高交点用线性插值；
   - 单位为 ns。
4. CCE 通过积分电荷计算：

```text
Q_col = ∫ I(t) dt * collapsed_thickness_um
Q_gen = raw_edep_total_eV / n_events / eh_pair_energy_ev * e
CCE = Q_col / Q_gen
```

其中 `step4_summary.json` 来自：

```text
SiC_electron/generation/<thickness>/output/<source>/step4_output/step4_summary.json
```

`fig5` 中 120um/75V 多源项对比使用：

```text
SiC_electron/output/<source>/step4_output/step4_summary.json
```

## 3. 能量分辨率结论

本窗口明确过：当前平均 i-t 曲线和总能量沉积不能计算严格能量分辨率。

原因：

```text
能量分辨率 R = FWHM_E / E_peak
```

需要 event-by-event 的能量或电荷分布，例如：

```text
Edep_i
Qcol_i
pulse_height_i
```

当前项目里的 `grid3d_100keV.csv` 等是多个事件累加后的空间沉积分布，没有 `EventID`，已经把事件涨落平均掉。因此当前只能算平均响应指标：

```text
CCE
FWHM_time
Ipeak
FOM_time_charge = (CCE / 100) / FWHM
```

不能从平均 i-t 直接得到能量分辨率。

## 6. C-14 最佳设计判据

用户觉得 Fig.6 看起来 50-60um 是最佳区间。我们把视觉判断转成了可写入论文的量化准则：

```text
高 CCE 平台 + 最短 FWHM
```

具体规则：

1. 先找当前扫描范围内最大 CCE：

```text
CCE_max = 97.731% at 100 um / 52 V
```

2. 若用 1.0 percentage point 平台窗口：

```text
CCE >= CCE_max - 1.0% = 96.731%
```

第一个满足条件且 FWHM 最小的点：

```text
50 um / 13 V
CCE = 96.831%
FWHM = 1.703 ns
Ipeak = 2.743 nA
```

3. 若用更严格的 0.5 percentage point 平台窗口：

```text
CCE >= CCE_max - 0.5% = 97.231%
```

第一个满足条件且 FWHM 最小的点：

```text
60 um / 19 V
CCE = 97.428%
FWHM = 1.741 ns
Ipeak = 2.743 nA
```

最终写入论文的 C-14 结论：

```text
推荐设计区间：50-60 um
名义推荐点：60 um / 19 V
```

不要再用旧的 `CCE-t90 Pareto` 或旧数值：

```text
旧 C-14 推荐 CCE = 97.332%, t90 = 6.559 ns
```

这些已经从当前论文 V2 中清除。
