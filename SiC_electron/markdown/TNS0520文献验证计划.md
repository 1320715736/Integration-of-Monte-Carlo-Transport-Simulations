本文档总结本轮对话中围绕新版 TNS 投稿思路、缺陷密度扫描、文献下载和文献验证形成的工作结论。后续优先按本文档执行“文献趋势验证”，再进入大规模结果整理和论文改写。

## 1. 新版文章主线

当前文章思路已经从无缺陷条件下的“高 CCE 平台 + 最短 FWHM”改为：

```text
4H-SiC PIN 探测器对 ¹⁴C 连续 beta 谱的响应优化
= i 区厚度 × 外延层材料质量 / trap density 的二维设计问题
```

核心论点：

1. ¹⁴C 是连续 beta 谱，不能简单用 49 keV 平均能量或 156.5 keV 端点能量单能粒子替代。
2. 理想材料下，CCE 随 i 区厚度增加而上升并趋于饱和，不自然产生唯一最优厚度。
3. 引入 Z1/2、EH6/7 等深能级缺陷后，厚器件受到更强 trapping/recombination 惩罚，CCE vs thickness 可能从单调饱和变成 peak + rollover。
4. 最终文章应给出不同材料质量 / trap density 下的推荐 i 区厚度曲线。

## 4. 关于 Imax 反常升高的判断

曾观察到：

```text
red:   Nt = 1e12
green: Nt = 0
```

在某条 120 um / 75 V 的 i-t 曲线中，`Nt=1e12` 的 `Imax` 略高于理想模型。

判断：

```text
这不一定异常。
```

原因：

1. `Nt=1e12 cm^-3` 对 ns 级瞬态而言不算强，载流子寿命可能仍远大于收集时间。
2. trap 在偏压求解阶段已经存在，可能改变静态电场分布，使早期感应电流更尖。
3. 缺陷可能削弱慢尾巴，使脉冲变窄，即使总积分电荷下降，峰值也可能上升。
4. `cathode TotalCurrent` 是感应电流，受速度场、权重场、空间电荷和 trap 占据影响。

因此后续验证不能以 `Imax` 为主，而应以积分电荷为主：

```text
Qcol = ∫ [I(t) - baseline] dt
CCE = Qcol / Qgen
```

判断标准：

```text
如果 Qcol(Nt) <= Qcol(Nt=0)，趋势正常。
如果 Qcol(Nt) 明显大于 Qcol(Nt=0)，需要检查 optical scaling、输入文件、trap 电荷、电场或积分口径。
```

## 7. Kim 2025 能验证什么

Kim 2025 不能用于绝对数值复现，因为它与本项目不同：

```text
Kim: 17 keV e-beam / Ni-63 mean energy, Silvaco ATLAS, betavoltaic J-V
本项目: ¹⁴C / 单能电子, Sentaurus, transient i(t)
```

但它非常适合做趋势验证。

Kim 中的：

```text
JSC 降低
VOC 降低
Pout_max 降低
```

对应本项目应观察的：

```text
Qcol = ∫ i(t) dt 降低
CCE 降低
```

也就是说，不要拿 `Imax` 对照 Kim，而要拿 `Qcol` 和 `CCE` 对照。

## 8. 需要用 Kim 2025 验证的四个趋势

### 8.1 trap density 增大时，积分电荷降低

对每条 i-t 曲线计算：

```text
Qcol(Nt) = ∫ [I(t) - baseline] dt
Charge ratio = Qcol(Nt) / Qcol(Nt=0)
Charge loss = 1 - Charge ratio
```

预期趋势：

```text
Nt=0        最大
Nt=1e11     几乎与 Nt=0 重合
Nt=1e12     轻微变化
Nt=1e13     开始明显下降
Nt=5e13     下降更明显
```

对应 Kim Fig.7：trap density 增加时 `JSC`, `VOC`, `Pout_max` 下降。

### 8.2 厚器件比薄器件更受 trap 影响

计算：

```text
Charge loss(thickness, Nt)
= 1 - Qcol(thickness, Nt) / Qcol(thickness, 0)
```

预期：

```text
10-30 um:  缺陷影响较小
60-130 um: 缺陷影响更明显
```

对应 Kim Fig.6：薄 i-layer 下 trap/no-trap 差别小，i-layer 变厚后差别变明显。

### 8.3 有缺陷后，CCE vs thickness 出现最优厚度

画图：

```text
x: i-region thickness
y: CCE or Qcol/Qgen
curves: Nt=0, 1e11, 1e12, 1e13, 5e13
```

预期：

```text
Nt=0: CCE 随厚度单调上升或饱和
低 Nt: 接近 Nt=0
高 Nt: 厚端 CCE 下降，出现 peak + rollover
```

这是新版文章的核心图，也对应 Kim Fig.6 中 “with trap” 情况下存在最佳 i-layer thickness 的结论。

### 8.4 可选：acceptor-only / donor-only 机制验证

Kim 的重要机制结论：

```text
acceptor-like trap 影响最大
donor-like trap 影响较小
i-layer 中的 trap 最关键
```

本项目当前是：

```text
Z1/2 acceptor + EH6/7 donor, 1:1
```

如果时间允许，选一个代表点额外跑：

```text
120 um / 75 V / C-14 / Nt = 5e13
```

三种 trap 条件：

```text
acceptor-only
donor-only
acceptor + donor
```

预期：

```text
acceptor-only 的 Qcol 损失最大
donor-only 较小
acceptor+donor 接近 acceptor 主导
```

如果成立，就能和 Kim Fig.7 的机制解释高度一致。

```text
Although the present work uses transient detector simulations rather than betavoltaic J-V extraction, the observed decrease of integrated collected charge with increasing trap density and the stronger degradation in thicker i-regions are consistent with the trap-assisted recombination trends reported by Kim et al. for 4H-SiC p-i-n betavoltaic cells.
```

中文含义：

```text
虽然本文采用的是瞬态探测器仿真，而不是 betavoltaic J-V 提取，

与 Kim 等人关于 4H-SiC p-i-n betavoltaic cell 中 trap-assisted recombination 的结果一致。
```
