## 二、最终保留的三个工作

### 1. 必做：Geant4–ESTAR 对照

这个是 **最重要的 Geant4 子模块验证**，工作量小，版面小，但对你的主结论帮助最大。

你的论文核心之一是：^14C 连续谱在 SiC 中形成的深度沉积分布不同于 20、49、100、156.5 keV 单能源项。这个结论依赖 Geant4 低能电子输运。如果审稿人质疑 Geant4 设置，后面的厚度优化都会被连带质疑。

NIST ESTAR 可以计算电子 stopping power、range 和 radiation yield，并且支持用户指定材料；这正好可以作为 4H-SiC 低能电子沉积的外部基准。([NIST](https://physics.nist.gov/PhysRefData/Star/Text/ESTAR.html?utm_source=chatgpt.com))

**最小做法：**

只做 20、49、100、156.5 keV 四个单能点，不必对 ^14C 连续谱单独做 ESTAR。

建议新增一个小表：

| Energy    | ESTAR (R_\mathrm{CSDA}) | Geant4 (z_{50}) | Geant4 (z_{90}) | (E_\mathrm{dep}/E_\mathrm{in}) |
| --------- | ----------------------- | --------------- | --------------- | ------------------------------ |
| 20 keV    |                         |                 |                 |                                |
| 49 keV    |                         |                 |                 |                                |
| 100 keV   |                         |                 |                 |                                |
| 156.5 keV |                         |                 |                 |                                |

这里 (z_{50})、(z_{90}) 定义为 Geant4 沉积能量累积到 50% 和 90% 的深度。你不要强行说 Geant4 (z_{90}) 必须等于 ESTAR (R_\mathrm{CSDA})，因为 CSDA range 是连续减速路径长度，不等于投影沉积深度。只要趋势、量级和厚度覆盖区间一致，就足够支撑 Fig.5。

**放在论文哪里：**

放在现在的 3.1 节后面，作为：

> 3.1.1 Geant4 electron-range benchmark

版面控制在 **半页以内**。一张小表即可，不一定另加图。

**对结论的帮助：**

它加强的是你的第一条结论：
**真实 ^14C 连续谱不能被 49 keV 或 156.5 keV 单能电子稳定替代。**

### 2. 必做：Geant4–TCAD 映射守恒 + 理想 CCE 极限测试

这是 **最便宜、最直接、最能堵审稿人口的内部一致性验证**。

你的论文现在已经有 425 个 TCAD 瞬态响应组合，覆盖 5 个源项、17 个厚度和 5 个缺陷密度。 你不需要再增加大量新仿真，只需要从已有数据里抽取几个关键检查项。

这个验证分两小步，但可以放在同一个表里，所以仍然算一个工作。

#### 2.1 映射守恒

你需要证明：

# [ N_{eh}^{Geant4}

\frac{E_\mathrm{dep}^{Geant4}}{E_{eh}}
]

和

# [ N_{eh}^{TCAD}

\int G(x,y,t),dVdt
]

是一致的。

建议新增表：

| Source    | (N_{eh}^{Geant4}) | (N_{eh}^{TCAD}) | Relative error |
| --------- | ----------------- | --------------- | -------------- |
| 20 keV    |                   |                 |                |
| 49 keV    |                   |                 |                |
| 100 keV   |                   |                 |                |
| 156.5 keV |                   |                 |                |
| ^14C      |                   |                 |                |

最好让误差小于 1%，如果能做到 <0.1% 更好。

#### 2.2 理想 CCE 极限

你需要证明在最理想条件下：

[
CCE \rightarrow 100%
]

否则审稿人会问：为什么无陷阱、全耗尽条件下，你的最高 CCE 只有约 97.8%？

你不需要展开讨论太多，只需要做一个控制仿真：

- 无陷阱；
- 载流子在 i 区内部均匀生成，或者选一个完全落在 i 区内的沉积分布；
- 足够长积分窗口；
- 全耗尽偏压。

然后给出：

| Test case                         | Expected result | TCAD result | Interpretation                               |
| --------------------------------- | --------------- | ----------- | -------------------------------------------- |
| Ideal uniform generation, no trap | (\approx 100%)  |             | Confirms transient-current integration       |
| Geant4 mapped ^14C, no trap       | (\approx 97.8%) |             | Includes entrance/depth-distribution effects |
| Geant4 mapped ^14C, (N_t=10^{13}) | Lower CCE       |             | Confirms trap-induced loss                   |

**放在论文哪里：**

放在 2.2 或 2.5 后面，作为：

> Mapping conservation and ideal-limit check

也可以放进讨论部分 4.3，替换你现在“间接验证”的一部分。版面大约 **三分之一到半页**。

**对结论的帮助：**

它加强的是你的第二、第三条结论：
**CCE 非单调不是数值映射错误造成的，而是缺陷俘获和漂移距离竞争造成的。**

### 3. 必做：Moscatelli 公开 SiC β 探测器实验 benchmark

这是三个里面唯一真正回应“没有实验对照”的。你没有实验条件，但可以做 **published experimental benchmark**。

Moscatelli 等研究了 40 μm 外延层 p(^+)/n SiC 探测器在 ^90Sr β 源下的电荷收集，给出了 β 辐照下的电荷收集结果和仿真对照；文献中器件外延层厚度约 40 μm，掺杂约 (1\times10^{15}\ \mathrm{cm^{-3}})，反偏最高到 900 V。([科学直通车](https://www.sciencedirect.com/science/article/abs/pii/S0168900205006443?utm_source=chatgpt.com))

这个 benchmark 不需要和你的 ^14C 结构完全相同。它的作用不是证明你的每个设计点都正确，而是证明：

> 同一类 SiC β 探测器中，TCAD 电荷收集模型可以复现实验 CCE–bias 趋势。

**最小做法：**

只复现一张曲线：

[
CCE(V)
\quad \text{or} \quad
Q_\mathrm{collected}(V)
]

用 WebPlotDigitizer 从 Moscatelli 图中提取 5–8 个实验点，然后用你的 Geant4–TCAD 流程建立一个 40 μm SiC p(^+)/n benchmark 器件。

不要把这个 benchmark 写得太大。不要讨论 ^90Sr 和 ^14C 的所有差异。只写：

> This benchmark is not intended to reproduce the present ^14C geometry. It is used to test whether the adopted TCAD charge-collection settings can reproduce the bias-dependent charge-collection trend of a published SiC beta detector.

建议新增一个图：

**Fig. X. Literature benchmark against Moscatelli et al.**

图中只放：

- digitized experimental points；
- your simulation curve；
- 简短误差说明，例如 MAPE 或平台区偏差。

**放在论文哪里：**

放在讨论 4.3，替换你现在的“与已有文献的间接验证”。你现在 4.3 主要是文字引用，审稿人会觉得不够硬。改成一个小 benchmark 图，反而更有说服力，版面增加不多。

**对结论的帮助：**

它加强的是整篇论文的可信度：
**虽然没有新实验，但仿真链条至少能复现公开 SiC β 探测器的电荷收集趋势。**

## 三、明确砍掉哪两项

### 砍掉 1：完整 Geant4 physics list 敏感性扫描

这个先不做。

原因是它会把你的文章引向“Geant4 模型比较论文”，偏离 4H-SiC PIN ^14C 探测器设计优化主线。TNS 里 Batic 那种论文本身就是 Geant4 验证论文，所以他们要比较版本、电磁模型和多重散射实现；你的文章不是这个方向。([arXiv](https://arxiv.org/abs/1307.0933?utm_source=chatgpt.com))

你只需要在方法里补一句：

> The electromagnetic physics list, production cut, step limiter, and number of primary particles are specified explicitly. The resulting electron range and deposited-energy profiles are benchmarked against ESTAR.

也就是说：**不做完整 physics list scan，但交代清楚 Geant4 设置，并用 ESTAR 做最低限度外部校验。**

### 砍掉 2：完整陷阱参数不确定性分析

这个也先不做。

原因是你现在的主线是“等效缺陷密度 (N_t) 驱动厚度回缩”。如果再扫描 (N_{Z1/2}/N_{EH6/7})、(\sigma_e)、(\sigma_h) 的大量组合，会把文章变成“陷阱参数不确定性论文”，而且会冲淡 Table 3 和 Table 5 的简洁设计结论。

你现在稿件已经说明 (N_{Z1/2}=N_{EH6/7}=N_t) 是设计空间假设，不是某一外延片 DLTS 拟合。 这句话保留即可。再在局限性里加一句：

> A full sensitivity analysis of the relative (Z_{1/2})/EH(_{6/7}) concentration and capture cross sections is beyond the scope of this work and will be addressed when DLTS-calibrated material data are available.

这样不会明显削弱你的结论。
